# 标书模板参考

## 中国标准标书格式规范

### 页面设置

| 项目 | 规格 |
|------|------|
| 纸张 | A4 (210mm × 297mm) |
| 页边距 - 上 | 2.54cm |
| 页边距 - 下 | 2.54cm |
| 页边距 - 左 | 3.17cm |
| 页边距 - 右 | 3.17cm |

### 字体要求

| 用途 | 字体 | 字号 | 磅值 |
|------|------|------|------|
| 正文 | 仿宋_GB2312 / 仿宋 | 四号 / 小四 | 14pt / 12pt |
| 一级标题 | 黑体 | 三号 | 16pt |
| 二级标题 | 黑体 | 小三 | 15pt |
| 三级标题 | 黑体 / 楷体 | 四号 | 14pt |
| 表格内容 | 仿宋 | 五号 / 小四 | 10.5pt / 12pt |

### 行距

- 正文行距：固定值 28磅
- 标题行距：固定值 28磅

### 标书常见结构

```
封面
投标函
法定代表人身份证明
授权委托书
投标保证金
一、投标报价表
二、资格证明文件
  2.1 营业执照
  2.2 资质证书
  2.3 业绩证明
三、技术方案（主要部分）
  3.1 项目管理方案
  3.2 服务接管方案
  ...
四、项目管理机构
五、其他资料
```

### 配图规范

| 图表类型 | 适用场景 | 格式要求 |
|---------|---------|---------|
| 流程图 | 流程描述、工作步骤 | SVG / HTML → PNG |
| 架构图 | 组织架构、系统架构 | SVG / HTML → PNG |
| 柱状图 | 对比数据、趋势 | HTML → PNG |
| 饼图 | 比例分配 | HTML → PNG |
| 表格 | 清单、对比、参数 | Word 表格 |

**禁止**：图表出现"图1-1"、"表2-3"等编号。图表直接呈现即可。
