# 评分办法解析指南

## 常见的关键词

在招标文件中，评分办法通常出现在以下章节：

- "评标办法"
- "评标方法"
- "评分标准"
- "评审细则"
- "评标办法前附表"
- "评分项"
- "评审因素"
- "详细评审"
- "技术评审"
- "商务评审"

## 解析方法

### 1. 读取法

搜索以上关键词，找到评标办法所在位置。通常在招标文件的"投标人须知"或"评标办法"章节。

### 2. 区分技术部分 vs 商务部分

- **技术部分**：服务方案、技术方案、实施计划、人员配置、管理体系等
- **商务部分**：报价、资质、业绩、财务状况等

本 skill 只关注技术部分，商务部分不处理。

### 3. 提取评分项

每个技术评分项通常包含：

```yaml
- 评分项名称: 服务方案
  总分: 24
  细项:
    - 名称: 项目管理方案
      分值: 4
      评审细则: 考察投标人项目管理方案...
      评审要素:
        - 流程控制
        - 计划管理
        - 岗位标准化
        - 质量管控
```

### 4. 拆解评审要素

从评审细则中提取关键词，作为标书章节的末级标题依据：

评审细则中通常包含"包括但不限于"字样的要素清单：
- "包括但不限于流程控制、计划管理、岗位标准化、质量管控" → 拆解为：流程控制、计划管理、岗位标准化、质量管控

### 5. 构建目录树

将评分项的层级结构转换为标书目录树：

```
- 服务方案 (24分)
  - 项目管理方案 (4分)
    - 流程控制
    - 计划管理
    - 岗位标准化
    - 质量管控
  - 服务接管方案 (4分)
    ...
```

## 注意事项

1. 标题名称必须与招标文件中保持一致
2. 分值越高的项应分配更多页数和篇幅
3. 评审细则中的每项要求都必须被响应
4. 注意"包括但不限于"后面的所有要素都需要覆盖
