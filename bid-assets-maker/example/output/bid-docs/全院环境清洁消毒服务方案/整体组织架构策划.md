## 整体组织架构策划

### 组织架构设置

针对广汉市人民医院后勤综合服务项目，我公司建立"三级管理、分区负责"的清洁消毒服务组织架构。项目占地170亩，建筑面积145003.09㎡，编制床位800张、设计床位1200张，涵盖门急诊医技楼、住院楼、感染楼、后勤楼、科教楼等多个建筑单体。根据医院建筑分布和服务需求，设置以下组织层级：

<img src="assets/org_structure.png">

**第一层级：项目经理（1人）**
全面负责广汉市人民医院清洁消毒服务项目的统筹管理工作，对接医院后勤管理部门，制定年度工作计划，组织质量考核，处理突发事件和投诉建议。

**第二层级：区域主管（3人）**
按照医院建筑功能分区，设置门急诊区域主管、住院区域主管、特殊区域主管各1名。负责分管区域的日常管理、人员调度、质量监督和培训指导工作。

**第三层级：班组长及一线保洁员**
根据各区域工作量配置班组长和保洁人员，病区设置病区组长，公共区域设置公共区域组长，特殊科室设置专项清洁组长。

### 管理运行机制

建立"日检查、周例会、月考核"的管理运行机制：

**日检查**：区域主管每日对管辖区域进行巡查，填写《保洁质量日检表》，发现问题现场整改或下发整改通知单。

**周例会**：项目经理每周组织召开工作例会，总结本周工作，布置下周任务，分析存在问题，制定改进措施。

**月考核**：每月对各区域、各班组进行综合考核，考核结果与绩效挂钩，连续两月考核不合格的人员予以调岗或辞退。

建立信息化管理平台，实现保洁任务派发、质量检查、问题整改、数据分析的全流程数字化管理，提升管理效率和服务质量。
