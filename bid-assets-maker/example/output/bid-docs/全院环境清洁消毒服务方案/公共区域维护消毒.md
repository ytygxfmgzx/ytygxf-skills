## 公共区域维护消毒

### 公共区域划分与标准

广汉市人民医院公共区域包括门诊大厅、走廊通道、卫生间、电梯轿厢、楼梯间、候诊区、停车场等。公共区域人流量大、接触面广，是清洁消毒工作的重点区域。根据《医院消毒卫生标准》（GB 15982-2012）和《公共场所卫生管理条例》要求，制定公共区域维护消毒标准。

**公共区域清洁消毒等级标准**

| 区域名称 | 清洁等级 | 清洁频次 | 消毒频次 | 质量标准 |
|---------|---------|---------|---------|---------|
| 门诊大厅 | Ⅰ级 | 每日4次 | 每日2次 | 地面光洁、无垃圾、无污渍、无异味 |
| 走廊通道 | Ⅰ级 | 每日4次 | 每日2次 | 地面干燥、墙面整洁、扶手光洁 |
| 卫生间 | Ⅰ级 | 每2小时1次 | 每日3次 | 无异味、无积水、洁具光洁 |
| 电梯轿厢 | Ⅰ级 | 每日4次 | 每日3次 | 地面光洁、按键消毒、轿厢无异味 |
| 楼梯间 | Ⅱ级 | 每日2次 | 每日1次 | 地面清洁、扶手光洁、无杂物 |
| 候诊区 | Ⅰ级 | 每日3次 | 每日2次 | 座椅整洁、地面清洁、空气清新 |
| 停车场 | Ⅱ级 | 每日1次 | 每周2次 | 地面无垃圾、无积水、标识清晰 |

### 公共区域维护消毒标准流程

**门诊大厅维护消毒流程**

门诊大厅是医院的门面，人流量最大，清洁消毒要求最高。

**保洁作业流程：**
1. 开业前准备（06:00-07:30）：全面清扫地面，擦拭所有物表，清洁玻璃门窗，整理导诊台
2. 早间保洁（08:00-09:00）：巡查清扫，清理垃圾，擦拭候诊椅
3. 上午保洁（09:00-11:30）：每30分钟巡查一次，及时清理垃圾，保持地面清洁
4. 午间保洁（11:30-13:00）：全面清扫，清理垃圾，擦拭物表
5. 下午保洁（13:00-17:00）：每30分钟巡查一次，及时清理垃圾
6. 晚间保洁（17:00-18:00）：全面清扫，垃圾清运，消毒处理

**消毒作业流程：**
1. 物表消毒：使用含氯消毒剂（250mg/L）擦拭候诊椅、导诊台、自助机等高频接触面
2. 地面消毒：使用消毒液拖地，作用30分钟后用清水拖净
3. 空气消毒：营业结束后使用空气消毒机消毒1小时

**走廊通道维护消毒流程**

走廊通道连接各科室，人流量大，需要保持畅通和清洁。

**保洁作业流程：**
1. 湿式清扫：使用消毒液浸润的拖把从一端向另一端拖地
2. 墙面清洁：擦拭墙面污渍、踢脚线
3. 扶手消毒：使用消毒液擦拭楼梯扶手、走廊扶手
4. 垃圾清理：及时清理走廊垃圾桶内的垃圾

**消毒作业流程：**
1. 扶手消毒：每日2次使用含氯消毒剂（250mg/L）擦拭
2. 地面消毒：每日2次使用消毒液拖地
3. 消防设施消毒：每月1次擦拭灭火器箱、消防栓等设施

**卫生间维护消毒流程**

卫生间是清洁消毒工作的重点和难点，需要高频次保洁和严格消毒。

**保洁作业流程（每2小时1次）：**
1. 清理垃圾：更换垃圾袋，收集废弃物品
2. 清洁洁具：使用洁厕剂清洁马桶、小便池，擦拭洗手台
3. 擦拭镜面：使用玻璃清洁剂擦拭镜面
4. 补充用品：补充擦手纸、卷纸、洗手液
5. 地面清洁：清扫地面，拖地，保持干燥

**消毒作业流程（每日3次）：**
1. 马桶消毒：使用含氯消毒剂（500mg/L）浸泡消毒，作用30分钟
2. 物表消毒：擦拭门把手、水龙头、冲水按钮等高频接触面
3. 地面消毒：使用消毒液拖地
4. 空气消毒：使用排风扇通风，保持空气流通

**电梯轿厢维护消毒流程**

电梯轿厢空间密闭，接触面集中，是交叉感染的高风险区域。

**保洁作业流程（每日4次）：**
1. 地面清洁：清扫地面垃圾，拖地
2. 墙面擦拭：擦拭轿厢内壁、镜面
3. 门轨清洁：清理电梯门轨内的杂物

**消毒作业流程（每日3次）：**
1. 按键消毒：使用75%酒精或消毒湿巾擦拭电梯按键
2. 扶手消毒：使用含氯消毒剂（250mg/L）擦拭扶手
3. 墙面消毒：使用消毒液擦拭轿厢内壁

### 公共区域特殊时段保洁

**就诊高峰时段（08:00-11:00，14:00-16:00）**
- 增加保洁人员配置，门诊大厅配备2名专职保洁员
- 每30分钟巡查清扫一次
- 及时清理垃圾，保持地面清洁
- 发现污渍立即清理

**雨雪天气**
- 在入口处铺设防滑地垫
- 增加地面拖擦频次，保持地面干燥
- 设置"小心地滑"警示标识
- 及时清理地面积水

**大型活动或检查**
- 提前进行深度清洁
- 活动期间全程保障
- 活动后及时清理恢复

### 公共区域质量检查标准

| 检查项目 | 检查标准 | 检查方法 | 检查频次 |
|---------|---------|---------|---------|
| 地面清洁度 | 无垃圾、无污渍、无积水 | 目视检查 | 每日4次 |
| 物表光洁度 | 无灰尘、无污渍、光洁明亮 | 目视检查+白手套擦拭 | 每日2次 |
| 卫生间无异味 | 无明显异味 | 嗅觉检查 | 每2小时1次 |
| 消毒记录完整性 | 记录完整、真实、及时 | 查阅记录 | 每日1次 |
| 垃圾桶清洁度 | 垃圾桶内外清洁、无异味 | 目视检查 | 每日1次 |
| 高频接触面消毒 | 消毒合格、记录完整 | ATP检测+记录检查 | 每周1次 |

建立公共区域清洁质量巡检制度，区域主管每日巡检不少于3次，项目经理每周巡检不少于2次，发现问题立即整改，确保公共区域环境整洁、安全。
