## 病区清洁消毒标准流程

### 病区清洁消毒标准

病区清洁消毒工作严格执行《医疗机构消毒技术规范》（WS/T 367-2012）和《医院消毒卫生标准》（GB 15982-2012）要求，建立标准化操作规程，确保病区环境安全。

**病区清洁消毒等级划分**

| 区域等级 | 适用科室 | 清洁消毒频次 | 消毒液浓度 | 特殊要求 |
|---------|---------|-------------|-----------|---------|
| Ⅰ类环境 | 手术室、产房、新生儿室 | 每日3次，随脏随洁 | 含氯消毒剂500mg/L | 空气消毒每日2次 |
| Ⅱ类环境 | ICU、供应室、透析室 | 每日3次，随脏随洁 | 含氯消毒剂500mg/L | 物表每日3次擦拭 |
| Ⅲ类环境 | 普通病房、诊室、治疗室 | 每日2次，随脏随洁 | 含氯消毒剂250mg/L | 地面湿式清扫 |
| Ⅳ类环境 | 卫生间、走廊、楼梯 | 每日2次，随脏随洁 | 含氯消毒剂250mg/L | 重点消毒高频接触面 |

### 病区清洁消毒标准流程

**病区清洁消毒标准操作规程**

**第一步：准备阶段**
1. 穿戴防护装备：工作服、口罩、帽子、橡胶手套、防水围裙
2. 检查清洁工具：拖把、抹布、消毒桶、榨水车等是否完好
3. 配置消毒液：按照不同区域要求配置相应浓度的含氯消毒液
4. 使用含氯消毒液浓度试纸检测消毒液浓度是否达标

**第二步：清洁阶段**
1. 湿式清扫地面：使用消毒液浸润的拖把从里向外、从洁到污顺序拖地
2. 擦拭物表消毒：使用消毒液浸润的抹布擦拭床头柜、床栏、门把手等高频接触面
3. 清洁卫生间：按"从洁到污"原则，依次清洁洗手台、镜面、马桶、地面
4. 更换垃圾袋：分类收集生活垃圾和医疗废物，更换新垃圾袋

**第三步：消毒阶段**
1. 物表消毒：使用消毒液擦拭后作用30分钟，再用清水擦拭
2. 空气消毒：使用紫外线灯或空气消毒机消毒，每次不少于30分钟
3. 终末消毒：患者出院或转科后，对床单元进行彻底消毒
4. 特殊消毒：感染患者床单元使用专用消毒工具，消毒液浓度加倍

**第四步：检查阶段**
1. 目视检查：检查地面是否清洁、物表是否光洁、卫生间是否无异味
2. 荧光检测：使用荧光标记法检测清洁质量，合格率≥90%
3. ATP检测：定期对高频接触面进行ATP生物荧光检测，合格标准≤100RLU
4. 微生物采样：每月对重点区域进行环境卫生学监测

**第五步：记录阶段**
1. 填写《病区清洁消毒记录表》，记录消毒时间、消毒区域、消毒液浓度、操作人员
2. 记录发现的问题及整改情况
3. 签字确认，交区域主管审核

### 病区清洁消毒频次安排

| 时间段 | 工作内容 | 涉及区域 | 质量标准 |
|-------|---------|---------|---------|
| 06:00-07:30 | 晨间清洁 | 所有病区 | 地面干燥、物表光洁、无异味 |
| 08:00-09:00 | 重点消毒 | 治疗室、处置室 | 物表消毒合格、空气消毒完成 |
| 11:00-12:00 | 午间保洁 | 卫生间、走廊 | 地面无积水、垃圾及时清理 |
| 14:00-15:00 | 下午消毒 | 所有病区 | 物表擦拭消毒、地面湿式清扫 |
| 17:00-18:00 | 晚间保洁 | 公共区域、卫生间 | 全面保洁、垃圾清运 |
| 20:00-21:00 | 夜间消毒 | 重点区域 | 空气消毒、物表消毒 |
| 随脏随洁 | 应急处理 | 污染区域 | 立即消毒处理 |

### 特殊病区清洁消毒规范

**感染性疾病科**
- 使用专用清洁工具，与其他病区严格区分
- 消毒液浓度提高至1000mg/L，作用时间延长至60分钟
- 清洁人员穿戴全套防护装备（防护服、N95口罩、护目镜、手套）
- 清洁工具使用后单独消毒处理，不与其他病区混用

**新生儿室**
- 使用低刺激性消毒剂，避免化学残留
- 清洁时间避开喂奶和探视时间
- 进入新生儿室前必须更换专用工作服、换鞋
- 空气消毒使用循环风紫外线空气消毒机

**重症医学科（ICU）**
- 物表每日消毒3次，使用一次性消毒湿巾
- 地面每日消毒3次，使用消毒液浸润拖把
- 呼吸机、监护仪等设备表面每日消毒2次
- 空气消毒每日2次，每次不少于1小时
