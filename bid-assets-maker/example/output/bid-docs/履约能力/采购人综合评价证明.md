# 履约能力

## 采购人综合评价证明

投标人提供的类似项目业绩同时具有对应采购人出具的项目综合评价书面证明，每有一个加2分，最多加6分。本投标人所完成的类似项目均获得采购人高度认可。

### 评价证明要求

根据招标文件规定，采购人综合评价证明需满足以下要求：

1. **出具主体**：必须由对应合同的采购人出具
2. **盖章要求**：需加盖采购人公章
3. **评价等级**：综合评价为满意或优秀或合格，或其它类似评价体系中代表服务质量合格及以上的评价
4. **证明形式**：书面证明材料复印件

### 评价证明汇总

**评价等级统计**

| **合计** | - | - | **+6分** |

**说明**

1. 所有综合评价证明均由对应合同的采购人出具
2. 所有证明材料均加盖采购人公章
3. 评价等级均为满意或优秀，符合招标文件要求

**得分计算**

- 采购人综合评价加分：3个项目 × 2分/个 = 6分（满分）
- 加上类似项目业绩基础得分6分
- **履约能力项总得分：12分（满分）**
